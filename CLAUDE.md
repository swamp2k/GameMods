# Repository instructions

- Read root `NOW.md` at the start of every session before working. Read `HANDOVER.md` where present, the relevant README files, and applicable nested instructions.
- Update root `NOW.md` before ending every session and keep it current as work progresses. Preserve relevant content and use these fields: Doing, State, Next step, Blocked by, Updated (YYYY-MM-DD). Base entries on verified findings and mark uncertainty explicitly. Create it only if missing.
- Keep root `AGENTS.md` and `CLAUDE.md` byte-for-byte identical. Whenever either root instruction file changes, update both identically, preserving useful existing instructions. Leave nested instruction files unchanged unless the user explicitly requests changes to them.
- If both root instruction files exist and differ, explain the differences and propose a merged version preserving useful instructions; wait for the user's choice before changing either file or continuing implementation.
